# 参考速度表

`reference-speeds.json` 给调度器估时用：某台设备对某个引擎没有实测速度时，按设备类型查这张表，结果标「参考值」。具体硬件的行里没有这一项、或者硬件不在表里时，本机和局域网设备退到最后一行「通用 CPU 8 核」。连它也没有的标「未测」：本机照样可用、估不出时间（自动推荐本机，`local_untested`），局域网设备不进推荐。

- 数字是 hard 难句每句秒数（合成），评测时再加每条打分秒数（`scorer`；0 表示表里的数已经含打分）。
- `train_sec_per_line`：默认训练参数（SoVITS 8 轮、GPT 15 轮）下每句训练数据的秒数，训练估时 = 准备 + 句数 × 轮数折算 × 它 + 训后评测。
- `match`：怎么认出设备。云端卡按卡型（`gpu`）完全相等；本机和局域网设备按硬件信息（`ttsapi/compute/hw.py` 的 `cpu`、`gpu`、`accel`）包含这个字符串，从上往下命中的行里第一条有这一项的为准；「通用 CPU 8 核」的 `match` 为空，谁都命中。
- `cloud_upload_mb_per_sec`：控制端往 Colab VM 上传输入的速度（2.4MB/s，控制端实测 917MB 约 6.5 分钟），云端开机准备 = 开卡、装环境 210 秒 + 上传量 ÷ 它。
- `engine_mem_gb`：跑这个引擎大约要多少内存，设备总内存不够时不进候选（规则 0）。

实测值的来源：测速（`python -m ttsapi.bench`、`POST /bench`，写进资料库 `compute/bench/<机器>/<时间>.json`）和任务完成后的移动平均（主控本地 `data/speeds.json`）。
